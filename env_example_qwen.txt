# 通义千问 + ChromaDB 环境变量配置示例
# 
# 使用说明：
# 方式1：系统环境变量（推荐）
#   export DEFAULT_LLM_API_KEY=your_api_key_here
#   export QWEN_MODEL=qwen-plus
#
# 方式2：.env 文件
#   创建 .env 文件并添加以下内容

# ============================================================
# 通义千问 API Key（必需）
# ============================================================
# 从 https://dashscope.aliyun.com/ 获取
DEFAULT_LLM_API_KEY=your_qwen_api_key_here

# ============================================================
# 模型配置（可选）
# ============================================================
# 可选值: qwen-turbo, qwen-plus, qwen-max, qwen-long
# 默认: qwen-plus
QWEN_MODEL=qwen-plus

# ============================================================
# 说明
# ============================================================
# 1. DEFAULT_LLM_API_KEY 可以用于任何兼容 OpenAI 的 LLM
# 2. 通义千问 API 地址已在代码中配置
# 3. 数据存储在本地 ./chroma_storage 目录
# 4. 不需要 MEM0_API_KEY（使用 ChromaDB 本地存储）
